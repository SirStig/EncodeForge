Open source · MIT License · v0.5.0-alpha-1 (PySide6, unreleased)

Encode, subtitle,
and organize your media

EncodeForge is a professional FFmpeg GUI built with PySide6. Hardware-accelerated batch encoding, v0.5.0 AI subtitles via faster-whisper (CTranslate2) — much faster and lighter than the OpenAI Whisper + PyTorch path in v0.4.x — plus smart media renaming, all in one app. Installable releases are still v0.4.1 (JavaFX; deprecated) until this line ships.

Download for Windows All Releases GitHub ↗
⚡

Hardware Acceleration

NVIDIA NVENC, AMD AMF, Intel Quick Sync, and Apple VideoToolbox — up to 10x faster than CPU encoding.

🤖

AI Subtitle Generation

v0.5.0: Local subtitles in 90+ languages with faster-whisper and GPU acceleration — dramatically faster than the v0.4.x Whisper stack. No cloud required.

🗂

Smart Media Renaming

Auto-detect and rename files using 10+ metadata providers including TMDB, TVDB, AniDB, and Trakt.

📦

Batch Processing

Queue entire libraries and process them overnight. Real-time progress tracking per file and overall.

🌐

8 Subtitle Providers

Download from OpenSubtitles, Addic7ed, Jimaku, SubDL, and more — with anime-specific sources built in.

🎬

Plex & Jellyfin Ready

Custom naming patterns compatible with Plex and Jellyfin. Preview all changes before applying.

💻

CLI Interface

CLI architecture is built and ready — encode, subtitle, and rename from scripts or shell. Full commands shipping in a future release.

🔓

Free & Open Source

MIT licensed. No telemetry, no subscriptions, no ads. Compiled with Nuitka for self-contained installs.

Hardware-Accelerated Encoding

AI-Powered Subtitles
