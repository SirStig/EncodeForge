Encode, subtitle,
and organize your media

A desktop FFmpeg app for hardware-accelerated batch encoding, smart renaming, and local AI subtitles with faster-whisper. 0.5.0 is the latest — Windows (.exe), macOS (Apple Silicon .dmg), and Linux (.deb, .rpm, AppImage) are on the download page and GitHub. Older 0.4.x builds are there too.

See it in action

Hardware-Accelerated Encoding

Transform entire video libraries with your GPU's dedicated encoding hardware. Configure codec, quality, audio normalization, and stream handling — then queue and walk away.

NVENC AMF QuickSync VideoToolbox Audio Normalization Stream Copy

AI-Powered Subtitles

0.5.x runs faster-whisper (CTranslate2) locally with GPU acceleration — quick and light on memory. Supports 90+ languages, multi-track output, and downloads from 8 subtitle providers as fallback.

faster-whisper GPU Accelerated 90+ Languages SRT / ASS / VTT Multi-track

Smart Media Organization

Automatically identify and rename movies, TV episodes, and anime using metadata from TMDB, TVDB, AniDB, Kitsu, Jikan, TVmaze, and more. Preview every change before it's applied.

TMDB TVDB AniDB Preview Mode Custom Patterns
