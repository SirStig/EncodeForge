# Screenshots

The PNGs in this folder (`encoding.png`, `subtitles.png`, `metadata.png`) are **legacy** captures of an older menu-bar / three-table layout.

The current EncodeForge desktop UI (0.5.0 line) uses:

- Frameless window with `AppTitleBar`
- Left sidebar navigation (Encoder, Subtitles, Metadata, Processes, Logs, Settings)
- Flat dark theme driven by `utils/design_tokens.py` + `resources/styles/theme_base.css`

Project-site and README callouts mark these images as outdated until fresh captures of the sidebar chrome land.
